# pmk-sites — правила для AI-ассистентов

Посадочные сайты ПМК Парк (11 доменов `*-хабаровск.рф`). Подробности — `README.md`.

## ⚠️ Главное правило: у каждого сайта сетки — свой уникальный дизайн

Каждый сайт делается со **своим** дизайном: своя цветовая палитра, свои шрифты,
своя типографика, скругления, иконки, логотип, композиция блоков и первого экрана.
- **Запрещено** копировать дизайн pmkpark.ru (лайм `#c8f000`, тёмный `#16191c`,
  Manrope, «квадратик»-мотив и т.п.) и дизайн других сайтов сетки.
- Перед началом сайта — предложить концепцию дизайна (палитра, шрифты, характер,
  набросок первого экрана) и получить подтверждение.
- Вести реестр в `docs/designs.md`: какие палитры/шрифты уже заняты — не повторять.
- Общим может быть только «невидимое»: код формы заявки, SEO-разметка, сборка, деплой.

## ⚠️ Без бренда ПМК: у каждого сайта своё название

- У каждого сайта **своё название и логотип** (согласовать вместе с концепцией дизайна).
- На сайтах сетки **не упоминать** «ПМК Парк», pmkpark.ru, логотип и фирменные мотивы ПМК.
- Контакты — тоже «свои»: подменный телефон, отдельная почта сайта, мессенджеры без
  «PMK» в имени. Не ставить `pmkpark@mail.ru`, `t.me/Vladimir_PMK_PARK` и т.п.
- Оператор ПДн (ИП) указывается **только** на странице `/politika/` — этого требует 152-ФЗ.

## ⚠️ Фото — только свои и только для одного сайта

- Никаких стоков. Только реальные снимки производства, отдельный набор на каждый сайт.
- Не использовать фото с pmkpark.ru и с других сайтов сетки (Яндекс сравнивает картинки).
- В кадре нет логотипов/вывесок ПМК, номеров машин, лиц без согласия.
- Фото кладутся в `sites/<slug>/photos/` и выводятся через `astro:assets` — сборка пережимает
  их в WebP и удаляет EXIF/GPS. Не подключать фото мимо `astro:assets` (уйдут с метаданными).
- Список кадров для фотографа — `docs/photos/<slug>.md`.

1. Показывай план и жди подтверждения перед изменениями на сервере.
2. Контент каждого сайта **уникальный**: не копировать тексты с pmkpark.ru и между сайтами
   (иначе дубли и аффилированность в Яндексе).
3. Телефоны на сайтах — **подменные** (коллтрекинг). Не ставить основной номер завода
   и сквозную ссылку на pmkpark.ru в подвал.
4. Общий код (форма, SEO, сборка) меняется в `src/` — правка разом влияет на все сайты.
   После правки собрать все (`npm run build:all`) и проверить хотя бы два.
5. Версии закреплены точно (Astro, PocketBase). Обновление — отдельной задачей.
6. Персональные данные: форма без галочки согласия не отправляется, `/politika/` обязательна.
7. Каждый деплой = git tag `vX.Y.Z` + запись в `CHANGELOG.md`.
8. После деплоя проверить curl-ом, что домен отдаёт новую версию, и отправить тестовую заявку.
