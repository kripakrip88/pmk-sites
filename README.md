# pmk-sites

Посадочные сайты ПМК Парк на доменах `*-хабаровск.рф` — **Astro** (статика) + **PocketBase** (заявки).

Один проект — много сайтов: у каждого сайта своя папка `sites/<slug>/` с конфигом,
текстом и **своим уникальным дизайном** (цвета, шрифты, композиция — см. `CLAUDE.md`).
Общий только «невидимый» код: форма заявки, SEO, сборка, деплой.
Сборка даёт готовый HTML в `dist/<slug>/`.

> ⚠ Пилот `lazernaya-rezka` пока в дизайне pmkpark.ru — по правилу его нужно переделать
> в собственный дизайн.

## Структура

```
sites/<slug>/site.json   # домен, SEO, контакты (подменный телефон!), блоки, FAQ
sites/<slug>/text.md     # SEO-текст статьёй (уникальный для каждого сайта)
src/components/          # блоки страницы: Hero, Materials, Steps, Advantages, Cta, Faq, LeadForm
src/layouts/Base.astro   # <head>, Метрика, цели, шапка/подвал
src/pages/               # главная, /politika/, 404, robots.txt, sitemap.xml
pocketbase/              # миграция коллекции leads + хук (письмо, вебхук n8n)
deploy/                  # nginx, Dockerfile PocketBase
docker-compose.yml       # VPS: nginx + pocketbase + certbot
```

## Команды

```bash
npm ci
SITE=lazernaya-rezka npm run dev      # разработка одного сайта
npm run build:all                     # собрать все сайты → dist/<slug>/
npm run nginx                         # сгенерировать deploy/nginx/sites.conf
```

Для локальной проверки формы: запустить PocketBase и собрать с
`PUBLIC_PB_URL=http://127.0.0.1:8090`. На сервере переменная не нужна — nginx
проксирует `/api/collections/leads/records` в PocketBase на том же домене.

## Новый сайт

1. Скопировать `sites/lazernaya-rezka/` → `sites/<slug>/`.
2. В `site.json` — домен, подменный телефон, счётчик Метрики, контент.
3. Свой дизайн (палитра, шрифты, композиция) — согласовать концепцию, внести в `docs/designs.md`.
4. `text.md` — **уникальный** текст (не копировать с pmkpark.ru и соседних сайтов).
5. `npm run build:all && npm run nginx`, деплой (см. `deploy/README.md`).

## Заявки

Форма → PocketBase `leads` (телефон, имя, комментарий, до 5 файлов-чертежей по 20 МБ,
UTM/yclid, страница, IP). Защита: honeypot-поле, обязательное согласие на ПДн,
не больше 5 заявок в минуту с IP, читать заявки может только админ, файлы закрыты.
После сохранения хук шлёт письмо (`LEADS_EMAIL`) и JSON в n8n (`N8N_WEBHOOK_URL`) —
дальше n8n заводит лид в ERP.

Цели Метрики: `lead_sent`, `phone_click`, `email_click`, `messenger_click`.
